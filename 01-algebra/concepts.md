Algebra — Concepts

1. What Is Algebra?

Algebra is a branch of mathematics that uses letters and symbols to represent numbers and relationships between quantities.

2. Variables

A variable is a symbol that represents a number.

Example:

x + 3 = 7

Here, x is the variable.

3. Solving a Simple Equation

Given:

x + 3 = 7

Subtract 3 from both sides:

x = 7 - 3

Therefore:

x = 4
